# ChordLens v9.1 실험판

기반: v7 전체 프로젝트.

- FFT 프레임의 크로마 변화를 이용해 화성 변화 후보를 찾습니다.
- 변화 후보 사이의 구간 전체 점수를 평균해 코드를 추정합니다.
- 구간 단위 동적 계획법으로 순간적 코드 변화에 페널티를 부여합니다.
- BPM은 최소 변경 간격의 참고값으로만 사용합니다. 고정 초/마디마다 코드를 나누지 않습니다.
- 기존 MP3, 카포, 악보, CSV, 구간 반복, YouTube 백엔드는 유지합니다.

주의: 실제 음원 정답 비교 전의 실험판입니다. 1초 미만 구간 감소가 정답률 향상을 보장하지 않습니다.

배포: 저장소 최상위에 파일을 덮어쓰고 Render 재배포 후 새로고침하세요.
