# ChordLens iOS PWA (초기 실행 가능 버전)

아이폰 Safari에서 홈 화면에 추가해 사용할 수 있도록 만든 웹 앱입니다. 음원 파일을 선택하면 브라우저의 Web Audio API로 코드 후보를 추정합니다. 분석은 휴대폰 브라우저 안에서 처리되며 업로드 파일은 별도 서버로 전송하지 않습니다.

## 포함 기능
- MP3/WAV/M4A 등 브라우저가 디코딩할 수 있는 로컬 음원 분석
- 코드 진행 타임라인, 코드 구간 탭 이동
- 기본 기타 운지표(일부 메이저/마이너 코드)
- 카포 위치 선택 및 기본 운지 폼 기반의 휴리스틱 추천
- 시작/끝 구간 반복 재생
- 코드 결과 CSV 내보내기
- PWA manifest/service worker 및 기본 오프라인 캐시
- 선택적 YouTube URL 음원 처리용 Python 서버 엔드포인트

## 빠른 로컬 실행 (Windows / macOS / Linux)
1. Python 3.10 이상을 설치합니다.
2. 터미널에서 이 폴더로 이동합니다.
3. `python backend/server.py` 실행
4. 같은 컴퓨터에서 `http://127.0.0.1:8000`을 엽니다.

로컬 파일 분석은 추가 Python 패키지 없이 사용할 수 있습니다. YouTube 링크 분석은 선택 기능이며, 호스트 컴퓨터에 `yt-dlp`와 `FFmpeg`가 설치되어 PATH에서 실행 가능해야 합니다. 링크 분석은 영상의 접근 권한 및 YouTube 이용 조건에 따라 실패할 수 있습니다. 다운로드 권한이 있는 콘텐츠에만 사용하세요.

## 아이폰에 설치
1. 앱 파일을 HTTPS를 지원하는 웹 호스팅에 올립니다(예: 정적 사이트 호스팅).
2. iPhone에서 Safari로 HTTPS 주소를 엽니다.
3. 공유 버튼 → **홈 화면에 추가** → 추가를 누릅니다.
4. 홈 화면의 ChordLens 아이콘으로 실행합니다.

PWA 설치는 HTTPS 주소가 필요합니다. ZIP 파일 자체를 아이폰에 저장하거나 `file://`로 여는 것만으로는 PWA 설치/서비스 워커가 동작하지 않습니다. 현재 ZIP에는 공개 HTTPS 배포 주소가 포함되어 있지 않으므로, 아이폰 설치를 위해서는 호스팅 단계가 필요합니다.

## YouTube 링크 기능에 대한 중요 안내
브라우저 페이지가 YouTube의 미디어 스트림을 직접 분석하는 것은 CORS 및 서비스 접근 제약 때문에 불가능합니다. 이 패키지에는 선택적 `/api/youtube-audio` 서버가 포함되어 있습니다. 서버에서 `yt-dlp`와 `FFmpeg`를 사용할 수 있어야 하며, 링크를 처리하는 동안 호스트 서버가 음원을 가져와 브라우저에 반환합니다. 정적 호스팅만으로는 이 기능이 활성화되지 않습니다. 실제 배포 시 API 서버를 HTTPS로 호스팅하고 같은 출처에서 제공하거나 `app.js`의 API 주소/ CORS 설정을 함께 구성해야 합니다.

## 분석 정확도 / 한계
- 이는 완성된 상용 음원 분석 엔진이 아닌 브라우저 내 코드 추정 MVP입니다.
- FFT 크로마와 장/단 3화음 템플릿으로 추정하므로 베이스가 강한 믹스, 디스토션 기타, 전위 코드, 7th/add9/sus 코드, 카포가 있는 원곡에서 오차가 날 수 있습니다.
- 카포 추천은 추정된 코드에서 기본 오픈 코드 운지가 얼마나 자주 가능한지 보는 단순 휴리스틱이며, 음악 이론적으로 최적이라고 보장하지 않습니다.
- 일부 코드만 운지표가 준비되어 있습니다. 코드 이름/운지표가 없는 경우에도 타임라인 분석 결과는 표시될 수 있습니다.
- iOS Safari의 실제 기기 성능과 파일 디코딩은 파일 길이 및 형식에 따라 달라집니다. 80MB 초과 파일은 앱에서 제한합니다.

## 개발자 테스트
- `node --check app.js` (JavaScript 문법 검사)
- `python -m py_compile backend/server.py` (Python 문법 검사)
- 로컬 실행 후 파일을 선택해 분석, 카포 변경, 반복 구간, CSV 저장을 수동 확인하세요.

이 패키지는 소스 코드와 실행 가능한 프로토타입입니다. 아이폰 실기기에서 테스트했거나 공개 서버에 배포했다고 주장하지 않습니다.
