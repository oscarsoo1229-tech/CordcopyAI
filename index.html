04

코드 진행 악보

재생 위치에 맞춰 현재 코드가 강조됩니다.

BPM은 직접 입력하거나 자동 추정할 수 있어요. 첫 마디 시작 위치를 맞추면 마디 정렬이 개선됩니다.

카포 없음 · 운지 코드 기준

BPM과 첫 마디 시작을 기준으로 코드를 마디·박에 배치합니다. BPM과 박자표는 추정 또는 수동 설정이며 정확한 채보를 보장하지 않습니다.

분석하면 코드 진행 악보가 표시됩니다.
05

정답 악보 비교 (v11.4)

코드·카포·마디 또는 시간을 입력하고 실제 분석 결과와 비교합니다.

이 기능은 분석 정확도를 평가할 뿐 학습하거나 코드 인식 결과를 자동 수정하지 않습니다. 악보와 MP3의 편곡·조성·재생 시점을 먼저 맞춰 주세요.

시작 마디,끝 다음 마디,악보 코드 (예: 9,11,G → 9~10마디)

음악을 들으며 악보 마디 시작점 맞추기

음원을 재생하다가 악보에서 해당 마디가 시작하는 순간 일시정지하고 버튼을 누르세요. 시간 표시가 정수 초만 보일 때는 아래에 소수점 시간을 직접 입력할 수도 있어요.

BPM과 박자를 먼저 맞춘 뒤 마디 시작점을 지정하세요. 자동으로 음원을 듣거나 시작점을 찾지는 않습니다.

위 ‘코드 진행 악보’의 BPM·박자·첫 마디 시작 값을 사용합니다. 첫 마디 시작은 1마디의 실제 시작 시간입니다. 맞추지 않으면 정확도 점수가 잘못 나와요.

정답을 입력하고 음원 분석이 끝나면 비교할 수 있어요. 예시 악보는 전체 곡 정답이 아닙니다.

점수는 정답 구간 중 실제로 분석 결과가 겹친 시간만의 일치율입니다. ‘기본 코드’는 근음 + 장·단화음 등 품질이 일치한 비율이며 7th 차이는 별도로 계산합니다. 정답이 아닌 구간은 평가하지 않습니다.
